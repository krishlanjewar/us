# 💑 Us – Couple Sync App (Flutter)

**Us** is a Flutter-based couple app designed to help partners stay connected, organized, and in sync through shared utilities like notes, to-dos, and timers.

This project was built as a **learning-focused application** to understand real-world Flutter development, backend integration, and offline-first app architecture.

---

## ✨ Features

### 🔗 Shared Features (Between Two Users)
- **Shared Notes**
  - Create, edit, and view notes visible to both partners
- **Shared To-Do List**
  - Add tasks, update status, and track completion together
- **Shared Timer**
  - Useful for focus sessions, reminders, or shared activities
